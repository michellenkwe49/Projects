This project is an intelligent document processing and data extraction pipeline designed to parse, categorize, and extract structured data from invoice and receipt files using AI and automated data workflows. The system features automated data extraction to parse raw financial documents and capture key metrics, vendor names, dates, and line items. It includes an interactive Jupyter Notebook file named Invoices & Receipts AI code.ipynb for exploratory data analysis, data cleaning, and model experimentation. Additionally, it incorporates a Streamlit web application via app.py for user-friendly file uploading, viewing processed results, and monitoring batch operations, alongside CSV batch processing datasets like batch1_1.csv and batch1_2.csv. 
The project directory structure is organized within the AI_FINAL_ASSIGNMENT_INVOICES&RECEIPTS folder, which houses the main Streamlit application, the batch processing CSV files, the core Jupyter Notebook for data processing logic, and an internal checkpoints directory. To set up the workspace, ensure you have Python 3.8 or higher installed, navigate to the project directory, and install the required dependencies such as Streamlit, Pandas, and any additional machine learning or OCR libraries needed for your specific setup. 
To run the application, you can launch the interactive dashboard interface by executing the Streamlit run command in your terminal, which opens a local web server in your browser. Alternatively, you can explore the data pipeline step-by-step by launching Jupyter Notebook with the core analysis file. The system processes digital or scanned invoice and receipt inputs through its script and notebook routines, outputting structured CSV logs containing cleaned and categorized transaction details. Contributions, issues, and feature requests are welcome to further enhance the codebase.
